# Language Studies

Each study applies the full set of 159 QLang questions to one programming
language. The studies are the project's proof of concept: every language
directory is an experimental answer to the same universal questions, so the
answers can be compared across languages rather than memorized as feature
lists.

A study is useful when it makes you disagree with the framework — the
{doc}`self-correction rule <../framework/12-mental-model>` says: if a language
defies the map, ask what question the map failed to ask.
